# UniCore — نظام إدارة وتحليل نتائج الطلاب

**تكليف المستوى الرابع | Task 2**

مشروع JavaScript من نوع Console-Based لتحليل نتائج الطلاب وتطبيق قواعد النجاح ولجنة الرأفة.

## تشغيل المشروع
1. افتح `index.html` باستخدام متصفح حديث.
2. افتح أدوات المطور Developer Tools.
3. انتقل إلى تبويب `Console`.
4. ستجد تقرير جميع الطلاب، ثم تقرير لجنة الرأفة.

اختصار فتح Console في أغلب المتصفحات على الكمبيوتر: `F12` أو `Ctrl + Shift + J`.

## متطلبات التكليف المطبقة
- `Student` class و`constructor` بأربع خصائص: `id`, `name`, `grades`, `attendance`.
- حساب المتوسط باستخدام `reduce()`.
- تحديد التقدير باستخدام `if / else`.
- تحديد النتيجة باستخدام العامل المنطقي `&&`.
- إنشاء أربعة كائنات داخل `studentsList`.
- استخراج الطلاب ذوي المتوسط من 40 إلى 49 باستخدام `filter()`.
- إضافة خمس درجات إلى متوسط كل طالب مؤهل باستخدام `map()` دون تعديل الدرجات الأصلية.
- جمع المتوسطات الجديدة باستخدام `reduce()`.
- حماية القسمة على صفر عند عدم وجود طلاب مؤهلين.
- عرض التقرير باستخدام `console.table()` و`console.group()`.

## حدود التقديرات
التكليف لم يحدد حدود التقديرات بالحروف؛ لذلك تم اعتماد التقسيم التالي ويمكن تعديله حسب تعليمات الدكتور:

| التقدير | المتوسط |
|---|---:|
| A | 90 فأكثر |
| B | 80 إلى أقل من 90 |
| C | 70 إلى أقل من 80 |
| D | 60 إلى أقل من 70 |
| E | 50 إلى أقل من 60 |
| F | أقل من 50 |

## ملاحظة أكاديمية
درجات الرأفة تضاف إلى **متوسط الطالب** فقط وفق نص التكليف، ولا يتم تغيير مصفوفة درجات المواد الأصلية. كما أن النجاح بعد الرأفة يظل مشروطًا بتحقق المتوسط 50 فأكثر والحضور 75% فأكثر.
